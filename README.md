# Lumora - A React Frontend Project

This project is a frontend implementation of the "Wonderous" application, originally a Flutter web project by Google. This version is built using React, TypeScript, and Vite.

## About The Project

The Lumora app showcases the Seven Wonders of the World with beautiful imagery and interactive elements. This project aims to replicate the user experience and functionality of the original web application for educational and portfolio purposes.

### Key Features Implemented:

- **Interactive World Map:** An introductory page with an interactive map to select a wonder.
- **Wonder Details:** Detailed pages for each wonder, including a timeline of its history and a gallery of artifacts.
- **Artifact Viewer:** A closer look at the artifacts with detailed descriptions.
- **Responsive Design:** The application is designed to be responsive and work on various screen sizes.
